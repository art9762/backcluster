# BackCluster engine overlay

The engine gitlink remains pinned to the published fork. `manifest.json` binds every patch to that exact commit and SHA256 content. `python3 -m tools.backcluster.engine_overlay` materializes a verified source tree under `.backcluster/engine-source/`; build scripts consume it. Generated source changes fail verification on the next build.

The patch implements native Qwen35 capacity inference through a head and two workers. Workers retain the only KV and GDN state for their own layers. A bounded pipeline overlaps three ubatches across the head, middle and tail. The middle returns the raw residual; the tail returns the last token's logits. Each stage checks source identity, layer range, output role, epoch, request order, positions and reply dimensions.

The existing SPT protocol version remains 2. Message IDs 19-23 add `STAGE_HELLO`, `STAGE_HELLO_OK`, `STAGE_CHUNK`, `STAGE_CHUNK_ACK` and `STAGE_RESTORE`. These packed, little-endian messages are defined in `tail-server.h`. Stage HELLO supplies an epoch and full source SHA256; replies declare residual or logits capability. Existing two-node clients keep their original message formats.

Set `LLAMA_SPLIT_DECODE=1`, `LLAMA_SPLIT_L=L`, `LLAMA_SPLIT_MIDDLE=IPv4:port`, `LLAMA_SPLIT_MIDDLE_END=M`, `LLAMA_SPLIT_TAIL=IPv4:port` and `LLAMA_SPLIT_MODEL_SHA256=<source SHA256>` for `[0,L)`, `[L,M)` and `[M,N)`. Each worker uses `llama-split-prefill --serve-tail PORT --tail-model SHARD`. The shard metadata must contain `split.layer_start`, `split.layer_end`, `split.n_layer_full` and `backcluster.source.sha256`. Three-stage timeouts must be finite; the default is 120 seconds.

A worker failure aborts both links and fails the decode. Recovery requires clearing the head and replaying the exact prefix from position 0. The stage restore command supports an opaque full local state snapshot and checks its watermark, but the native coordinator does not persist or restore distributed checkpoints. The Python adapter checkpoint toolkit is a separate API. Only one sequence, consecutive text positions, last-token logits and no speculative decoding are supported.

The patch also corrects text M-RoPE residual positions, rejects oversized framing and forged inner state counts, closes failed sockets before joining threads, uses unique temporary state files, and provides loaded-model callbacks for the iOS identity receipt. Capacity mode avoids whole-model prefetch and copies active GPU tensors into compact buffers so inactive file regions cannot be wired through an arbitrary GGUF tensor ordering. CPU inactive weights remain mapped; capacity builds must retain mmap and disable repacking.

Run `scripts/test-native-pipeline.sh` for the real CPU integration gate. It generates deterministic untrained hybrid GDN/attention weights, compares monolithic and split logits, tests f32/f16 transport and the legacy two-node path, suspends each worker to test cancellation/recovery, and checks state snapshot/restore and malformed requests. It requires CMake and a C++17 compiler, with no downloaded model or Python numerical package. Apple builds, production weights, transport throughput, startup memory peaks, jetsam and thermal behavior remain device acceptance work.
